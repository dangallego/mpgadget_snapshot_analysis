# MP-Gadget Snapshot Analysis

Python tools for analyzing MP-Gadget simulation snapshots, including methods for working with particle data, identifying dark matter halos, and computing physical quantities like angular momentum and total energy.

## Features

- Load and filter snapshot data (positions, velocities, potentials, etc.)
- Compute:
  - Group angular momenta
  - Kinetic and potential energy
  - Center of mass and barycenters
- Plot:
  - 2D/3D particle distributions
  - Angular momentum vectors
  - Velocity fields
- Extract and analyze particles by group or ID

## Requirements

This package is intended for **post-processing** snapshots generated by [MP-Gadget](https://github.com/MP-Gadget/MP-Gadget). To generate your own simulations or snapshots, please refer to their [installation guide](https://github.com/MP-Gadget/MP-Gadget#installation).
